# LG Optimizer for Lampa

![Version](https://img.shields.io/badge/version-1.4.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-WebOS%20%7C%20Tizen-lightgrey.svg)

Оптимизационный плагин для приложения Lampa. Разработан специально для устройств с ограниченными аппаратными ресурсами (в первую очередь смарт-телевизоров под управлением LG WebOS и Samsung Tizen). Цель проекта — минимизировать задержки интерфейса, снизить нагрузку на CPU/GPU и оптимизировать потребление оперативной памяти.

## Технические особенности (v1.4.0)

Плагин работает на уровне системных вызовов браузера и включает в себя независимые модули, каждый из которых решает конкретную проблему производительности ТВ-платформ:

* **Кэширование DOM-шаблонов:** Использование нативного метода `cloneNode` вместо постоянного парсинга HTML-строк. Повышает скорость рендеринга каталогов и объемных списков до 20 раз.
* **Адаптивная навигация (Fast-nav):** Динамическое отключение ресурсоемких CSS-переходов (`transition` и `animation`) при быстром серийном нажатии кнопок пульта. Позволяет избежать потери кадров (frame drops) и удерживать 60 FPS при навигации.
* **Throttling событий:** Ограничение частоты вызова тяжелых обработчиков (`keydown`, `scroll`, `timeupdate` плеера) с использованием `requestAnimationFrame`. Устраняет инерцию пульта и освобождает вычислительные ресурсы для декодирования видео.
* **Аппаратное ускорение:** Принудительное делегирование растеризации карточек каталога на видеочип (через `transform: translateZ(0)` и `backface-visibility`), что исключает лишние циклы Reflow/Repaint у родительских контейнеров.
* **Многоуровневый буфер Storage:** Асинхронная батч-запись в `localStorage`. Критичные данные (например, позиция плеера) пишутся мгновенно, а второстепенные состояния интерфейса сохраняются с задержкой (debounce), исключая микро-фризы UI.
* **Сетевая оптимизация:** Дедупликация параллельных `fetch`-запросов, защита от `null`-ответов API и применение `DNS prefetch` для заблаговременного разрешения адресов TMDB и Кинопоиска.
* **Ленивая загрузка (Lazy Load):** Эффективная загрузка изображений строго в зоне видимости с помощью `IntersectionObserver`, освобождающая лимит HTTP-соединений браузера телевизора.

## Установка

Для подключения плагина добавьте следующую ссылку в настройках приложения Lampa:  
`Настройки` → `Расширения` → `Добавить плагин`

```text
https://raw.githack.com/WotexLampa/lampa-lg-optimizer/main/plugin.js
```

## Конфигурация

Плагин предоставляет собственный интерфейс управления. После установки в главном меню настроек Lampa появится раздел **«LG Оптимизатор»**. 

В данном разделе можно точечно включать или отключать функциональные модули плагина (например, отключить аппаратное ускорение карточек или буферизацию пульта) в зависимости от особенностей конкретного телевизора.

> **Примечание:** Изменение большинства параметров требует перезагрузки приложения для вступления в силу.
