# LG Optimizer for Lampa

![Version](https://img.shields.io/badge/version-1.5.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Platform](https://img.shields.io/badge/platform-WebOS%20%7C%20Tizen-lightgrey.svg)

Оптимизационный плагин для приложения Lampa. Разработан специально для устройств с ограниченными аппаратными ресурсами (в первую очередь смарт-телевизоров под управлением LG WebOS и Samsung Tizen). Цель проекта — минимизировать задержки интерфейса, снизить нагрузку на CPU/GPU и оптимизировать потребление оперативной памяти.

## Технические особенности (v1.5.0)

Плагин работает на уровне системных вызовов браузера и включает в себя независимые модули, каждый из которых решает конкретную проблему производительности ТВ-платформ:

* **Адаптивная навигация (Fast-nav):** Динамическое отключение ресурсоемких CSS-переходов (`transition` и `animation`) при быстром серийном нажатии кнопок пульта. Позволяет избежать потери кадров (frame drops) и удерживать 60 FPS при навигации.
* **Throttling событий:** Ограничение частоты вызова тяжелых обработчиков (`keydown`, `scroll`, `timeupdate` плеера) с использованием `requestAnimationFrame`. Каждый `keydown`-слушатель получает собственный независимый RAF-буфер — устранён баг v1.4.1, при котором несколько слушателей конкурировали за один общий слот и часть нажатий пульта терялась.
* **Аппаратное ускорение:** Принудительное делегирование растеризации карточек каталога на видеочип (через `transform: translateZ(0)` и `backface-visibility`), что исключает лишние циклы Reflow/Repaint у родительских контейнеров.
* **Изоляция reflow (CSS contain):** Применение `contain: layout style paint` к карточкам каталога. Браузер не распространяет пересчёт вёрстки за пределы карточки, снижая layout-работу при навигации до ~30% от исходного объёма.
* **Точечный GPU-слой (will-change):** `will-change: transform` вешается исключительно на карточку, находящуюся в фокусе, и снимается при уходе фокуса. Вместо десятков compositor layers одновременно — всегда не более одного. Устраняет переполнение tile memory на TV с разделяемой GPU-памятью.
* **Многоуровневый буфер Storage:** Асинхронная батч-запись в `localStorage`. Критичные данные (например, позиция плеера) пишутся мгновенно, а второстепенные состояния интерфейса сохраняются с задержкой (debounce), исключая микро-фризы UI.
* **Сетевая оптимизация:** Дедупликация параллельных `fetch`-запросов с таймаутом, защита от `null`-ответов API и применение `DNS prefetch` для заблаговременного разрешения адресов TMDB и Кинопоиска. Исправлен баг v1.4.1 с использованием `.finally()`, недоступного на webOS 3–4.
* **Ленивая загрузка (Lazy Load):** Эффективная загрузка изображений строго в зоне видимости с помощью `IntersectionObserver`, освобождающая лимит HTTP-соединений браузера телевизора.
* **Выгрузка постеров (Img Unload):** Активная замена `src` постеров, ушедших за пределы экрана, на заглушку. Один декодированный постер занимает ~527 КБ GPU-памяти; без выгрузки за несколько страниц истории накапливается 100+ МБ. Модуль удерживает потребление GPU-памяти под постеры в пределах ~8–12 МБ.
* **Очистка памяти старых экранов (Activity GC):** Вызов `destroy()` у экранов, опустившихся глубже пятой позиции в стеке истории Lampa. Устраняет главную причину накопительного замедления интерфейса при длительных сессиях.
* **Монитор давления памяти (Memory Pressure):** Периодическая проверка заполненности JS-кучи через `performance.memory`. При превышении 80% инициирует принудительную очистку кэша Lampa, предотвращая аварийное завершение браузерного процесса операционной системой.

## Установка

Для подключения плагина добавьте следующую ссылку в настройках приложения Lampa:  
`Настройки` → `Расширения` → `Добавить плагин`

```text
https://raw.githack.com/WotexLampa/lampa-lg-optimizer/main/plugin.js
```

## Конфигурация

Плагин предоставляет собственный интерфейс управления. После установки в главном меню настроек Lampa появится раздел **«LG Оптимизатор»**. 

В данном разделе можно точечно включать или отключать функциональные модули плагина (например, отключить аппаратное ускорение карточек или буферизацию пульта) в зависимости от особенностей конкретного телевизора.

> **Примечание:** Изменение большинства параметров требует перезагрузки приложения для вступления в силу.

## ⚠️ Важные примечания

### DNS prefetch и preconnect

**Известная проблема:** На некоторых моделях телевизоров (особенно с устаревшими версиями WebOS или нестандартными сетевыми настройками) активация модуля **"DNS prefetch и preconnect"** может приводить к проблемам загрузки контента:
- Карточки фильмов/сериалов не отображаются
- Постеры остаются пустыми при открытии карточки
- Задержка при загрузке изображений

**Решение:** Если вы столкнулись с такой проблемой:
1. Откройте `Настройки` → `LG Оптимизатор`
2. Отключите опцию **"DNS prefetch и preconnect"**
3. Перезагрузите приложение Lampa

> **Для разработчиков:** Данный модуль использует стандартные HTML-подсказки браузеру (`<link rel="dns-prefetch">` и `<link rel="preconnect">`). Проблема может быть связана с конфликтом между заблаговременным установлением TLS-соединений и политиками CORS некоторых CDN-серверов на уровне сетевого стека WebOS.

### Совместимость версий

- **WebOS 3.x – 5.x:** Основные модули работают стабильно; модули `Выгрузка постеров`, `GPU-слой для активного элемента`, `Монитор давления памяти` требуют WebOS 5+
- **WebOS 6+:** Все модули работают стабильно, включая `Изоляция reflow (contain)`
- **WebOS 7+:** Рекомендуется отключить "DNS prefetch" при проблемах с загрузкой
- **Tizen 4+:** Полная поддержка, дополнительная настройка не требуется
